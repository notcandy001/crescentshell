## 🧠 Overview

CrescentShell is a notch driven Wayland bar built with:

- **Hyprland**
- **Quickshell**
- **Qt 6**

The goal is to create a clean, modular, focused shell component with my dotfiles 

## 🛠 Requirements

- Hyprland  
- Quickshell (git recommended)  
- Qt 6  
- Wayland session
